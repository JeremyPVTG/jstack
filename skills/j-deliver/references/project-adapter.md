# Project adapter contract

Keep product-specific facts in the project, discovered from its current instructions: base branch, required commands, allowed runner, workflow inputs, risk approval actors and expiry, merge policy, and runtime verification expectations.

A skill name, a saved receipt, or an old approval cannot supply missing current project state. Preserve valid standing authorization within its scope. Ask only for missing authority or a material unresolved decision; do all independent authorized preparation first.

If current tools differ from historical examples, use their documented contract. A delegate's result is evidence to verify, not permission to publish or merge.
